# 篩選測驗線上練習

國中小數學「篩選測驗」已公布回饋訊息年度的選擇題（434 題），由老師在《篩選測驗選題台》組卷後產生練習卷連結／QR Code，學生輸入班級與座號即可作答，不需登入。

- 線上網址：https://ryansu2021.github.io/screening-practice/ （需搭配老師產生的練習卷連結，`#s=...`）
- 練習模式：每題立即回饋，答錯可再試一次（提問引導，不直接給答案）
- 檢測模式：全部做完才看結果
- 作答回傳到老師的 Google 試算表（Apps Script 網頁應用程式）；斷線時暫存在裝置上，恢復連線後自動補送
- 支援電腦、平板（橫／直）與手機直式

題目圖由原始試卷 PDF 裁切，不含答案標示；答案以雜湊比對，不以明文寫在頁面中。
